# DevOps Auto Kit

面向中小企业运维开发场景的 DevOps 实战知识库。

本仓库主要沉淀 Jenkins、Kaniko、Harbor、Kubernetes、ArgoCD、Prometheus、Alertmanager、企业微信告警、Ansible、Shell、Python、CMDB、发布系统等真实场景中的模板、脚本和排障 Runbook。

## 主要模块

- CI/CD 发布流程：Jenkins、Kaniko、Harbor、ArgoCD、Kustomize
- Kubernetes 排障：Pod、CronJob、PVC、Ingress、Service、Supervisor
- 监控告警：Prometheus、Alertmanager、PrometheusAlert、企业微信、钉钉、AI 告警分析
- 自动化脚本：Shell、Python、Ansible
- CMDB 实践：硬件资产采集、资产模型、发布系统对接
- 发布系统实践：Django DRF + Vue 运维发布系统设计

## 适合人群

- 运维工程师
- 运维开发工程师
- DevOps 工程师
- 中小企业技术负责人
- 准备 DevOps / Kubernetes / SRE 面试的同学

## 说明

本仓库内容来自真实运维开发场景，但所有内容均已脱敏和泛化处理。生产环境使用前请结合自身环境验证。
