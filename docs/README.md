# 文档与 Runbook

本模块主要沉淀 DevOps、Kubernetes、监控告警、CMDB、发布系统等方向的文档、排障 Runbook 和设计说明。

## 建设目标

通过本模块整理可长期复用的文档体系，重点解决以下问题：

- 将零散排障经验整理成标准 Runbook。
- 将 Jenkins、ArgoCD、Kustomize 等发布流程整理成文档。
- 将 Prometheus、企业微信告警、AI 告警分析整理成方案。
- 将 CMDB、发布系统、运维平台建设思路整理成设计文档。
- 为后续发掘金、CSDN、博客园等平台提供基础内容。
